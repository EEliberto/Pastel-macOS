# 登录流程模拟（仅 Debug）

在 Xcode 打开 `Pastel.xcodeproj`，选择 Pastel scheme，确认 Run 使用 Debug 配置，按 ⌘R。
进入“设置 → Apple 账户”，点击账户标题行右侧的“登录流程测试”。正式 Release/DMG 不显示这个菜单。

## 场景

- **需要验证码**：模拟第一次认证返回 `[2FA]`，自动打开真正的验证码弹窗。
- **模糊认证失败**：模拟返回 `[AUTH]`；点击“已收到验证码？输入验证码”打开同一个验证码弹窗。
- **验证等待中取消**：提交验证码后等待 10 秒；点击“取消”应返回原账户表单，等待超过 10 秒也不会重新弹窗或保存账户。

## 模拟验证码

- `123456`：成功，关闭登录流程。
- `000000`（或其他六位数字）：失败，保留验证码弹窗并显示错误，可再次输入。
- `999999`：过期，保留验证码弹窗并显示过期提示。
- 少于或多于六位、包含非数字：确认按钮不可用。

点击验证码窗口“取消”会回到原表单，保留账户与密码供修改；再次点击“保存”可重复测试。
模拟账户为 `test@example.invalid`，密码是无效的测试占位值。

模拟使用独立的 AccountStore，复用真实的认证结果处理、验证码界面和取消逻辑；
在启动任何 Apple/Node 进程前截获模拟请求。成功时不会写入真实账户、Keychain、保险库或会话，
也不改变设备 GUID。所有模拟代码及菜单受 `#if DEBUG` 限制。

这可以重复验证界面与状态处理，但不能证明 Apple 服务端真实登录可用；真实登录仍需单独测试。
