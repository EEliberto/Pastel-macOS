# Pastel 20261108

**感谢你使用 Pastel！**

本次更新修复近期 Apple 账户登录与下载失败的问题，并改进多任务下载体验。

此次更新内容：

1. 更新 Apple 账户认证与下载流程，恢复登录、获取 App 和下载功能。
2. 支持多个下载任务并行传输。单个任务下载缓慢时，后续任务可继续进行，减少相互等待。
3. 加密保存并复用认证状态，减少重复登录与下载前的准备时间。
4. 改进登录和下载进度提示，显示等待、准备、认证及打包等状态，避免开始下载前一直显示 0%。
5. 为认证等待和网络请求增加超时处理，避免登录持续转圈或任务长时间无响应。
6. 根据 Apple 返回的信息区分密码错误、需要双重认证、验证码无效及服务异常，改进重试时的提示。
7. 移除已失效的受信任设备手动获取验证码指引，并更新各语言提示。

首次使用新版时，可能需要重新登录并完成双重认证；首次准备认证组件所需时间取决于网络状况。

如果你在使用 Pastel 时遇到任何问题，请在 Github 中提交 Issue。
