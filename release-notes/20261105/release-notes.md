# Pastel 20261105

**感谢你使用 Pastel！**

本次更新修复“不再更新”功能失效的问题，并包含 IPA 账户信息兼容性改进。

本次修复：

1. 修复“不再更新”开关未传入下载组件，导致仍保留 App Store 更新识别元数据的问题。
2. 开启“不再更新”后保留账户显示信息及授权文件，生成独立的 `_no-update.ipa`，避免覆盖普通下载文件。
3. 修复首次获取免费 App 后重试下载时，未应用“不再更新”选项的问题。

已下载的受影响 IPA 需要勾选“不再更新”后重新下载并安装，旧文件不会自动修改。

同日此前更新内容：

1. 修复新版下载的 IPA 在资料库中 Apple 账户显示为空的问题。
2. 恢复 IPA 账户元数据的兼容字段与 XML 格式，提高第三方安装工具识别账户信息的兼容性。
3. 资料库兼容读取不同账户字段以及 XML、二进制 plist；此前已下载文件中存在的账户信息也可正常显示，无需重新下载。
4. 保留 IPA 的 App 内容、签名与账户授权文件，完善打包失败时的文件保护。

如果你在使用 Pastel 时遇到任何问题，请在 Github 中提交 Issue。
