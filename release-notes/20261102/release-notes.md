# Pastel 20261102

**感谢你使用 Pastel！**

本次更新重点修复 Apple 账户登录问题，并改善更新后的启动与凭据使用体验。此次更新内容：

1. 修复部分用户近期无法登录 Apple 账户的问题。
2. 更新 Apple 登录流程，正确使用 Apple 当前服务配置返回的认证地址。
3. 修复认证地址跳转后可能出现空响应、商店令牌换取失败或双重认证状态丢失的问题。
4. 登录跳转后继续保留 SAP 签名、Cookie、验证码和认证次数，并限制凭据只发送到有效的 Apple 服务地址。
5. 修复 20261102 初始构建中 Sparkle 签名身份不一致，导致 App 无法启动的问题。
6. 优化账户凭据保护，减少更新后反复要求输入 Mac 登录密码的情况；已有账户和会话会自动迁移。
7. 继续支持 macOS 26，并修复其他已知问题和细节体验。

如果你在使用 Pastel 时遇到任何问题，请在 Github 中提交 Issue。
