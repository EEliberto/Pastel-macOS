# Pastel 20261102

此更新优化了 Apple 账户凭据与会话的本机保护方式，解决更新 Pastel 后可能反复要求输入 Mac 登录密码的问题。

- Apple 账户密码现在集中保存在 AES-GCM 加密保险库中，macOS Keychain 只需保护一个随机主密钥。
- 现有账户密码、加密会话和设备标识会在需要时自动迁移，无需用户重新添加账户或手动导入证书。
- 保留已有 Apple 登录会话，避免仅因存储升级而要求所有账户重新登录。
- 为正式构建启用固定发布签名身份，使 macOS 能在后续更新中持续识别同一个 Pastel，减少重复的 Keychain 授权提示。
- 会话主密钥在单次运行期间安全缓存，避免同一次使用过程中重复访问 Keychain。
- 改进凭据保险库的原子写入、完整性校验和文件权限保护；只有验证写入成功后才完成旧凭据迁移。
- 继续支持 macOS 26，并保留 Node.js 24 LTS、JIT 权限和 Sparkle 更新验证。

从旧版首次升级时，macOS 可能会要求授权一次以读取旧凭据；自动迁移完成后，后续更新不应再逐个账户反复询问电脑密码。

建议所有用户安装此更新。
